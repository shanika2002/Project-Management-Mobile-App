# Project Management Mobile App

A Flutter-based mobile application developed for **Airport and Aviation Services (Sri Lanka) (Private) Limited**, at Bandaranaike International Airport, Katunayake. The app provides an intuitive interface, real-time backend integration, and interactive dashboards to support project tracking and decision-making.

## Overview

The Project Management Mobile App is designed to make project information easier to access and monitor from a mobile device. It brings project tracking and dashboard views into a streamlined mobile experience.

## Key Features

- **Project tracking:** Access and monitor project information through the mobile application.
- **Interactive dashboards:** View project-related information in a visual format.
- **Backend integration:** Connect the Flutter interface with backend services for up-to-date information.
- **User-friendly interface:** Navigate project information using an intuitive mobile UI.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code with Flutter support
- An Android emulator or physical device
- Access to the application's configured backend, where required

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Project-Management-Mobile-App.git
   ```
2. Open the project directory:
   ```bash
   cd Project-Management-Mobile-App
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Configure any required backend endpoint settings using your approved development configuration.
5. Run the application:
   ```bash
   flutter run
   ```

> Replace `YOUR_USERNAME` with your GitHub username. The setup instructions assume a standard Flutter project; adjust them if your repository has a different structure.
